# MINHA POSTURA PROFISSIONAL

Landing page para a atividade "Minha Postura Profissional".

## Arquivos

- index.html → estrutura e conteúdo
- style.css → visual, cores, layout e responsividade
- script.js → menu mobile, compromissos interativos e animações

## Como abrir

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o `index.html`.
4. Use o Live Server ou abra o arquivo diretamente no navegador.

## Identidade visual

Inspirada na referência enviada:
- Azul claro
- Rosa
- Preto
- Branco
- Tipografia grande e editorial
- Contornos pretos e sombras fortes

## Conteúdo incluído

1. Capa
2. O que é postura profissional?
3. Como se comportar nos espaços da escola
4. Atitude que parece pequena, impacto que pode ser grande
5. Soft Skills em ação
6. Eu no mercado de trabalho
7. Código de Boas Práticas
8. Desafio final

A página também possui navegação, responsividade e interação no Código de Boas Práticas.
